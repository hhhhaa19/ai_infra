复习笔记

每个模块按学习顺序写成连贯讲解：这部分讲什么 → 一步步展开 → 自测。RMSNorm 的完整讲述和面试追问见 RMSNorm 专题。

面试要求怎么看

每个模块在「自测」前加了一块「面试要求」，按推理优化 / 端侧部署 / CUDA 算子方向常见的面试内容分三档：必须会 = 不看资料能当场讲清或写出来，答不上来基本会被判定为"没真正做过"；应该会 = 能讲清原理、写出关键片段、结合自己的项目举例；加分 = 知道是什么、解决什么问题，能说出思路。各模块的「高频问题」并进了自测。档位是按这类岗位常见面试内容整理的经验判断，具体公司会有差异。

通用原则：面试官最常问的不是"这是什么"，而是"你为什么这么做、你怎么知道它有效、数字是多少"。每个模块都准备一个自己做过的具体例子 + 一个数字。

另外一定会考、但不在这些模块里的

  • 手写 CUDA 题：reduction、softmax（含 online softmax）、transpose（shared memory + 避免 bank conflict）、GEMM 分块、scan、LayerNorm / RMSNorm。
  • Attention / FlashAttention：标准 attention 的计算和显存、FlashAttention 的分块 + online softmax、为什么能省显存访问（讲解见模块 16）。
  • LLM 推理系统：KV cache、PagedAttention、continuous batching、prefill / decode 分离（vLLM / SGLang 的核心概念）。
  • 算法题：LeetCode Hot 100，每天 1～2 题。
  • 八股：操作系统（进程 / 线程、虚拟内存、页表）、计算机组成（缓存、流水线）、C++（见模块 3）。
  • 项目讲述：RMSNorm 和 ACT 两个项目，各准备一个 2 分钟版本和一个 10 分钟版本，每个都要有"问题 → 做法 → 数字 → 局限"。
