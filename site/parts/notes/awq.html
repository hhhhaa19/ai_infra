AWQ：从权重到 INT4 量化

这篇论文讲什么：大模型权重太占显存，想把它压成 INT4，又不想效果变差太多。AWQ 的思路是：先看哪些输入通道重要，调整权重的数值分布，再量化。这里只学了原理，没有做量化实验。

1. 先分清权重和 activation

一层线性计算写成 y = Wx。W 是权重，固定不变；x 是 activation，随输入变化。一个输入通道对应 x 的一个分量，也对应 W 的一列；一个输出通道对应 W 的一行。量化的是 W，但后面会看到，决定误差影响的是 x。

2. INT4 怎么表示一个权重

INT4 只有 16 种编码，所以要用步长 Δ 和零点 z 把编码还原成实数：ŵ = (q − z)Δ。例如 Δ=0.1、z=6、q=9，还原值是 0.3；如果原值是 0.32，差出来的 0.02 就是量化误差。

整层共用一组 Δ、z 太粗糙，所以沿 W 的每一行分组，组内共享 Δ 和 z。这里的 group 是一组输入通道对应的权重，不是一组 token。

3. 为什么要看 activation

同样的权重误差 ε，对输出的影响是 ε·xj。xj 大的通道，误差会被放大，所以更重要。AWQ 用少量校准文本统计各通道的幅度，这属于训练后量化（PTQ）。

4. 通道缩放：让重要通道的误差变小

知道哪些通道重要后，怎么保护它们？可以把 W 的第 j 列乘 sj，同时把 xj 除以 sj。两者相乘的结果不变，这是量化前的等价变换。然后量化调整后的 W′。

W′ = WS,  x′ = S⁻¹x,  W′x′ = Wx            // 量化前的等价变换
ŷ = Q(WS) S⁻¹ x                            // Q 为量化后还原的近似权重
ŵ = (q − z)Δ                               // group 内反量化

放大某列后，这一列的量化误差在还原时被除以 sj，相对变小了。但放大也可能让组内数值范围变大，Δ 跟着变大，反而增加误差。所以 s 不能直接取大，要通过搜索来定。

这里有两个尺度：sj 作用于一列，Δg 作用于一行里的一个 group。s 改变分布后，Δ 要重新计算。

5. 推理时怎么用

常见配置是 W4A16：权重用 INT4 存储，activation 用 16 位，kernel 按需反量化。所以 W4A16 不代表所有计算都是 INT4。量化后必须评测完整模型，不能只看某一层的误差。
